# 利用ガイド

## 参加と読み上げ

通常のVCに参加して `/join` を実行します。VC接続とVOICEVOXのウォームアップが完了すると、準備完了音が流れます。VC付属チャットへの投稿を「表示名 本文」の順に読み上げます。表示名はサーバーのニックネームを優先します。ステージチャンネルには対応していません。

読み上げはサーバーごとに投稿順で処理します。準備中の投稿も待機し、Bot投稿と直近1000件の重複IDは無視します。待機上限は20件、本文は200文字、URL解析は3件までです。添付画像や取得不能なリンクは通知用の文言に置き換えます。読みは `assets/dictionary.json` で設定できます。

`/leave` はBotと同じVCの利用者が実行できます。人がいなくなると既定60秒で自動退出します。退出すると読み上げ・動画の再生と待ちリストを破棄します。キューはメモリ管理のため、再起動後の復元はありません。

## 動画の再生と操作

準備完了後に `/play <url>` で動画を追加します。再生中の動画がなければ開始し、再生中なら末尾に追加します。映像は送信しません。

- 対応範囲は通常の公開動画、1本2時間以内です。ライブ・終了済みライブ・認証が必要な動画には対応していません。
- プレイリスト全体は追加できません。動画IDを含むURLの `list`・`index`・`start_radio` などは除去し、その動画1本を追加します。
- 再生中1件と待機20件をサーバーごとに管理します。取得失敗はVCのチャットへ通知し、後続へ進みます。
- `/pause` は動画だけを一時停止し、`/resume` は同じ位置から再開します。読み上げは継続します。
- `/skip` は取得中・一時停止中でも現在の動画を破棄し、後続があれば再生します。
- `/list` は現在の動画と待機中の動画をタイトル付きリンクで表示します。タイトルは最大8秒で取得し、失敗時はURLを表示します。成功した結果はキュー内で再利用し、失敗したものは次の表示時に再取得します。長いタイトルは60文字に省略します。サムネイルは表示しません。

動画操作・リスト表示はBotと同じVCの利用者のみ実行できます。`/help` はVC参加前でも使えます。コマンド応答は実行者だけに表示します。

一時停止の反映には送信準備済み音声（約100ms）とDiscord側のバッファによる遅延があります。1動画125分の実時間上限には一時停止時間も含み、期限切れ・取得失敗時は一時停止を解除して後続へ進みます。

## 音量

| 対象 | ゲイン |
| --- | --- |
| 動画の通常再生 | 元音声の12.5% |
| 読み上げ中の動画 | 通常再生時の15%（元音声の1.875%） |
| 読み上げ | ミキサーでは100%。合成時の音量は `VOICEVOX_VOLUME` で設定 |

動画の減衰・復帰は60msのease-in-out（smoothstep）で変化します。読み上げ中も動画の再生位置は進み、読み上げ終了・エラー・キャンセル時に通常音量へ戻ります。数値は信号ゲインの比率で、知覚上の音量比ではありません。音源ごとの自動音量正規化は行いません。

## 利用条件とクレジット

音声合成の既定話者は **VOICEVOX:ずんだもん** です。Botプロフィールやサーバーの案内にも表記し、話者を変更したらクレジットを合わせてください。

[VOICEVOX利用規約](https://voicevox.hiroshiba.jp/term/)・[Q&A](https://voicevox.hiroshiba.jp/qa/)・[キャラクター利用規約](https://zunko.jp/con_ongen_kiyaku.html)を確認してください。Engineのライセンスと音声・キャラクターの利用条件はそれぞれ適用されます。

動画は[YouTube利用規約](https://www.youtube.com/static?template=terms)と権利者の条件に従って利用してください。公開動画でも地域制限・レート制限・Bot判定・サイト側の変更により取得できない場合があります。Cookie・認証による取得や制限回避には対応していません。
